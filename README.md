# 仮想ドラフト会議サイト

「仮想ドラフト 2026」の開催案内・進行状況・結果を公開する閲覧専用サイトです。
指名データの正本は Google スプレッドシートで、サイトはそれを読み取って表示するだけです（書き込みは行いません）。

- ビルド不要の静的サイトです（HTML / CSS / JavaScript のみ）。GitHub Pages、Netlify、Cloudflare Pages など、任意の静的ホスティングにフォルダごと置けば動きます。
- ローカル確認：`python3 -m http.server 8000` を実行し、http://localhost:8000/ を開きます。

## ページとURL

| URL | 内容 |
| --- | --- |
| `/#/` | トップページ（開催前は案内、会議中はライブ会議室への入口） |
| `/#/2026` | 2026年ドラフトボード（`/#/2019`〜`/#/2025` で各年度に直接アクセスできます） |
| `/#/2026/teams` | 球団一覧 |
| `/#/2026/giants` | 球団別ページ（ID は `js/config.js` の `teams[].id`） |
| `/#/archive` | 年度別アーカイブ |
| `/#/rules` | ルール・選択手順（NPB の選択手順・概要の引用） |

動作確認用に `?phase=live`（`before` / `after`）を付けると、日時に関係なく会議中などの表示を確認できます。例：`/?phase=live#/2026`

## データ取得元（`js/config.js`）

運営スプレッドシート（`spreadsheetId`）の年度別タブ「2019 指名リスト」〜「2026指名リスト」を gid で指定済みです。シートの共有設定は「リンクを知っている全員が閲覧可」のままにしてください。

- 2027年以降は、新しい年度のタブを作ったら `years` にその gid（タブを開いたときの URL 末尾 `#gid=` の数字）を追加し、`currentYear` と `event` を更新します。
- 開催情報・ルール・参考資料・球団の表記と色も同じファイルで編集できます。
- 「ルール」ページ（`#/rules`）の NPB 選択手順・概要は、2026年版の公表まで **2025年版を暫定引用** しています（`npb`）。NPB が 2026年版を公開したら、`npb` の年・URL・本文と `references` の2件目・3件目を 2026年版に差し替え、`provisional: false` にしてください。引用元は転載禁止のため、抜粋にとどめ、出典と原文リンクは消さないでください。
- 取得元を設定していない年度は**デモデータ**（架空の選手名）で表示され、画面にも「デモデータ」と表示されます。

## シートの読み取りルール

現在のシート（「フォーマット」タブと同じ形）をそのまま読み取ります。

- 「球団名」の行（球団名が6つ以上並ぶ行）を見出しとし、その左の列を項目名として扱います。球団の並び順はシートの列順のままです。
- 項目名は「担当者」「明言」「1位指名①〜⑤」「1位」〜「N位」「育成1位」〜を認識します。右側の合計・ポジション別指名数の欄は使わず、サイト側で集計します。
- **ポジション**は、2行目の凡例（投手・捕手・内野手・外野手）と同じ**セルの背景色**から判定します。色が付いていないセルは「不明」として数えます。
- **1位の抽選結果**は、「1位」行に入った選手から判断します（複数球団が入札した選手が「1位」行に入った球団を当選とします）。「1位」行が未入力のあいだは「抽選待ち」と表示されます。
- 「選択終了」「不参加」は選手として数えず、ボード上に「選択終了」と表示します。担当者の「？」は「未定」と表示します。
- 別の書式（縦持ち形式など）にも対応しています。見本は [data/template-grid.csv](data/template-grid.csv)・[data/template-long.csv](data/template-long.csv)。

## 更新・障害時の動作

- 会議中（`event.start`〜`event.end`）は約60秒ごとに、それ以外は10分ごとに再取得します（`pollIntervalLive` / `pollIntervalIdle`）。タブを表示し直したときと「今すぐ更新」を押したときにも再取得します。
- 画面には最終更新時刻（最後に取得できた時刻）を表示します。
- 取得に失敗した場合は、前回取得できたデータ（ブラウザに保存した分を含む）をそのまま表示し、エラーと運営シートへのリンクを出します。
- 取得にはシートの HTML 表示（セルの色まで読めるもの）を使い、取れない場合は CSV（色なし＝ポジション不明）に切り替えます。どちらもリンク共有だけで読めます。キャッシュされないため、シートの更新は次回の取得（会議中は最大約60秒後）で反映されます。

## 会議後のアーカイブ

2026年のタブはそのまま残せば、アーカイブとして表示され続けます。シートを消す予定がある場合は、タブを CSV でダウンロードして `data/2026.csv` に置き、`years[2026] = { csvUrl: 'data/2026.csv' }` にしてください。2019〜2025年も同じ方法で保存済みの CSV に切り替えられます。
2027年に向けては `currentYear`・`event`・`years` に新しい年度を追加します。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     デザイン（ライト／ダーク、PC／スマホ対応）
js/config.js      開催情報・ルール・リンク・球団・データ取得元（運営が編集）
js/data.js        シート取得・整形・キャッシュ
js/app.js         画面描画・URL・自動更新
js/demo.js        取得元未設定時のデモデータ
data/             シート書式の見本
```
